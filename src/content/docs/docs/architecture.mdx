SnapDog is designed for ultra-low latency, lossless multi-room synchronization, and robust smart home automation. The entire system is built in pure Rust around an asynchronous event loop powered by `tokio` and structured diagnostics using `tracing`.

## Core Systems & Pipelines

### The ZonePlayer Engine
Each audio zone runs as an isolated, concurrent `tokio` task known as a `ZonePlayer`. It handles the complete lifecycle of audio streaming, decoding, and digital signal processing (DSP) independently:

* **Stream Decoding:** Reads and decodes compressed formats on-the-fly using `symphonia` (a pure Rust decoder suite) supporting MP3, FLAC, AAC, and OGG/Vorbis.
* **Stream Preemption (AirPlay 2 / Spotify):** ZonePlayers host embedded network receivers (Shairplay & Librespot) that automatically preempt active HTTP decodes when a user starts casting.
* **Software DSP:** Raw float PCM samples are piped through a parametric equalizer (N-band cascade biquads, computed in software) and a speaker correction database applying cabinet Spinorama profile parameters.
* **Encoding & Writing:** Processed samples are encoded with the configured codec and queued into the server buffers. The codec is set once, with `[snapcast].codec` or `--codec`: `pcm` (uncompressed), `flac` (lossless, the default), `f32lz4` (raw float with LZ4) or `f32lz4e` (the same, encrypted with a pre-shared key).

### The Embedded Snapcast Server
Instead of wrapping external binaries, SnapDog integrates a rewritten, high-performance Snapcast server ([snapcast-rs](https://github.com/metaneutrons/snapcast-rs)):
* **Frame Syncing:** Audio chunks carry timestamps. Each client estimates the clock difference to the server from time-sync messages (the Snapcast protocol, not NTP) and plays every chunk at its scheduled time.
* **Drift correction:** The client compares what it plays with the schedule. Small deviations are corrected with a slight change of the playback rate (soft sync), large ones by jumping (hard sync).
* **One codec for all clients:** The server streams in the one codec you configured. It does not switch codecs by itself depending on the network.
