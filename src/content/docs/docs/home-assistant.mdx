The SnapDog integration shows your zones in Home Assistant as media players and offers volume, mute, playback, playlists and the equalizer as entities and services. It talks to the [REST API](/docs/api-rest) and listens to the [WebSocket API](/docs/api-websocket), so state changes appear without polling.

The integration lives in its own repository, [`SnapDogRocks/snapdog-homeassistant`](https://github.com/SnapDogRocks/snapdog-homeassistant). It is not yet part of the HACS default list and not part of Home Assistant core. Until it is, you install it as a custom repository or copy it by hand. Both ways are supported.

## Requirements

* Home Assistant **2026.10** or newer.
* SnapDog **0.30.0** or newer. The integration needs `GET /api/v1/eq/presets` and the corrected API contract from that release.
* Network access from Home Assistant to the SnapDog server (port `5555` by default).
* The API key, if you enabled Bearer authentication in `snapdog.toml` (`[http].api_keys`).

The integration installs its Python library [`pysnapdog`](https://pypi.org/project/pysnapdog/) from PyPI when Home Assistant loads it. The Home Assistant host therefore needs access to PyPI for the first start.

## Install with HACS (custom repository)

This is the recommended way. HACS installs from the GitHub releases and shows updates.

<Steps>

1. Open HACS in Home Assistant, choose the menu in the top right and select **Custom repositories**.
2. Enter `https://github.com/SnapDogRocks/snapdog-homeassistant` as the repository and **Integration** as the type, then select **Add**.
3. Search for **SnapDog** in HACS, open it and select **Download**.
4. Restart Home Assistant.

</Steps>

## Install by hand

Use this if you do not run HACS. You will not get update notices.

<Steps>

1. Download the source archive of the latest release from the [releases page](https://github.com/SnapDogRocks/snapdog-homeassistant/releases).
2. Copy the folder `custom_components/snapdog` into the `custom_components` folder of your Home Assistant configuration directory. Create that folder if it does not exist.
3. Restart Home Assistant.

</Steps>

## Set up the integration

<Steps>

1. Go to **Settings → Devices & services → Add integration** and search for **SnapDog**.
2. Enter the host name or IP address of the SnapDog server, the port and, if you use one, the API key.
3. Confirm. Every zone becomes a media player, every client a device.

</Steps>

<Aside type="note">
  If you update SnapDog, update the integration too. The integration refuses servers older than its minimum version and says so in the setup dialog.
</Aside>

## When the integration becomes official

Two steps are planned once enough people have used it: inclusion in the HACS default list, which makes the manual repository entry unnecessary, and later a proposal for Home Assistant core. Your settings and entities stay as they are in both cases. This page will describe the change when it happens.

## Problems

Report problems at [`snapdog-homeassistant/issues`](https://github.com/SnapDogRocks/snapdog-homeassistant/issues) and include the Home Assistant version, the SnapDog version and the log lines of the `custom_components.snapdog` logger.
