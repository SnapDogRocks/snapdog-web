---
title: SnapDog Update CLI
description: Update SnapDog OS devices with the snapdog-update operator tool.
---

`snapdog-update` is a workstation and automation CLI for updating a remote SnapDog OS device through the [`snapdog-ctrl` API](/docs/api-snapdog-ctrl). It installs signed RAUC bundles (`.raucb` files) and accepts nothing else. The older raw-image flash path was removed from SnapDog OS, and the tool no longer has it.

## Installation

On macOS with Homebrew:

```shell
brew install snapdogrocks/tap/snapdog-update
```

You can also download a release archive from the [snapdog-os releases](https://github.com/SnapDogRocks/snapdog-os/releases). Archives exist for macOS, Linux and Windows, each for x86_64 and aarch64, with a checksum file next to every archive and an aggregate `SHA256SUMS`. Verify the checksum before you run the binary.

## Signed RAUC update

```shell
snapdog-update \
  --url http://snapdog.local \
  --file snapdog-os-pi4-0.10.4.raucb
```

The tool checks authentication and system health, validates the target board when it can infer both board models, uploads the bundle, triggers RAUC, follows installation progress, reboots the device, and verifies that the new slot booted. Supply an enabled control-panel password with `--password` or `SNAPDOG_PASSWORD`.

## Automation

```shell
snapdog-update \
  --url http://snapdog.local \
  --file snapdog-os-pi4-0.10.4.raucb \
  --password "$SNAPDOG_PASSWORD" \
  --non-interactive \
  --no-progress \
  --output json
```

JSON output is newline-delimited on stdout; diagnostics and progress use stderr. `SNAPDOG_URL` can replace `--url`. The default overall timeout is 30 minutes and the default status-poll interval is 2 seconds; override them with `--timeout-mins` and `--poll-secs`.

## Options

| Option | Description |
|---|---|
| `--url`, `-u` | Base URL of the device. Can also come from `SNAPDOG_URL`. |
| `--file`, `-f` | Path to the signed `.raucb` bundle. |
| `--password`, `-p` | Control-panel password. Can also come from `SNAPDOG_PASSWORD`. Not needed if authentication is off. |
| `--non-interactive` | Never prompt. Missing input becomes an error. |
| `--no-progress` | No progress bars, even in a terminal. |
| `--output` | `human` (default) or `json`. |
| `--timeout-mins` | Overall timeout in minutes (default 30). |
| `--poll-secs` | Status-poll interval in seconds (default 2). |

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Update completed successfully. |
| `1` | Validation, authentication, upload, installation, reboot, or verification failed. |

Run `snapdog-update --help` for the complete option list.
